# importacao-projuris

Coloque aqui as planilhas exportadas do Projuris (por exemplo `Pessoas.csv` e `Processos.csv`).

**Tudo nesta pasta é ignorado pelo Git**, exceto este arquivo. As planilhas têm dados reais
de clientes (CPF, endereço, filiação) e, pela LGPD, não podem ir para o GitHub nem para o
`seed.js`. A importação é feita pelo botão "Importar do Projuris" do protótipo, no navegador,
e os dados ficam só no computador de quem importa.
